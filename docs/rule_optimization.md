# 规则优化指南

## 一、姿态规则优化 (posture_rules.json)

### 当前姿态类型
- 探索性姿态
- 执行性姿态
- 评价性姿态
- 情感性姿态
- 混合姿态

### 优化方法

#### 1.1 增加关键词
```json
{
  "name": "执行性姿态",
  "keywords": ["做", "实现", "写代码", "执行", "完成", "帮忙", "写一个", "怎么弄", "操作", "部署"],
  "weight": 1.0,
  "min_matches": 1
}
优化建议：

增加同义词：如"搞"、"弄"、"整"等口语化词汇

增加场景词：如("排序", "算法", "接口", "数据库")

调整权重：高频词weight设为1.2~1.5

1.2 调整匹配规则
min_matches: 需要匹配的关键词数量

weight: 规则权重，影响置信度计算

1.3 添加新姿态
json
{
  "name": "新姿态名称",
  "keywords": ["关键词1", "关键词2"],
  "weight": 1.0,
  "min_matches": 1
}
二、清晰度规则优化 (clarity_rules.json)
清晰指标
json
"clear_indicators": {
  "keywords": ["因为", "所以", "首先", "然后", "具体", "明确", "确定", "清楚"],
  "min_length": 5,
  "has_punctuation": true
}
模糊指标
json
"vague_indicators": {
  "keywords": ["大概", "可能", "也许", "好像", "随便", "都行", "不知道", "说不清"],
  "too_short_threshold": 3,
  "repetition_threshold": 0.3
}
优化建议
增加清晰关键词：如"第一步"、"其次"、"最后"

增加模糊关键词：如"差不多"、"大约"、"貌似"

调整长度阈值：根据实际场景调整

添加更多语言特征

三、提醒模板优化 (remind_templates.json)
模板结构
json
{
  "templates": {
    "姿态名称": {
      "title": "标题",
      "content": "提醒内容"

  }

优化建议
根据用户反馈调整语气

增加具体行动建议

添加示例或场景说明

区分正式/轻松语气版本
